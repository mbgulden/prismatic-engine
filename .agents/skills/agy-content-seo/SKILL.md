# agy-content-seo

## Purpose

Let AGY do content-engine work with strategy and evidence, not generic SEO fluff.

## When to Use

Use for Active Oahu, BeyondSaaS, content briefs, schema, internal linking, local/multilingual SEO, search intent, and conversion-copy improvements.

## Operating Loop

1. Identify page/business goal.
2. Determine search intent and audience vocabulary.
3. Audit page: title/H1/H2/content/schema/internal links/CTA.
4. Compare SERP/competitors.
5. Produce brief or patch.
6. Verify rendered page/schema/links.

## Required Artifacts

- Intent summary
- Content gaps
- Title/H1/meta recommendations
- Schema changes
- Internal link targets
- CTA/conversion note
- Evidence list

## Quality Bar

- Output must be artifact-backed, not vibes.
- AGY should state assumptions and constraints explicitly.
- AGY should surface blockers instead of inventing missing facts.
- AGY should verify with external proof when the lane touches code, UI, APIs, or deployments.

## Pitfalls / Do Not Do

- Do not invent tour details, prices, reviews, locations, or form IDs.
- Do not conflate activeoahu.com with activeoahutours.com.
- If source is missing, leave a clean blocker.
